# Test design specification and manual cases

**Status:** Designed, not claimed manually executed. Automated counterparts are
listed in `TRACEABILITY.md`; their measured outcomes do not constitute manual signoff.
Start from `npm run aut:ready` and the seeded four-product Europe catalog. EUR 10
T-Shirt variant SHIRT-S-BLACK; CG10 = 10% on items; standard shipping EUR 10;
zero tax rate in the supplied seed. Use new customer/cart per case.

| ID     | Preconditions and procedure                                                                                                                | Expected result and oracle                                                                                                                                                                      | Risk / automation                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |

Compare variant ID and regional API price.             | R-CATALOG; API-001/002, UI-001/002                                 |
| MAN-02 | Search `T-Shirt`; clear; search a unique nonexistent string; clear and check Shirts category.                                              | One matching product; clearing restores four; unmatched query shows an empty result; Shirts filter leaves the T-Shirt. No console error replaces results.                                       | R-CATALOG/R-ERROR; API-003/004, UI-009–011                         |
| MAN-03 | Fresh session: add one T-Shirt; visit cart; select 3; reload; select 10.                                                                   | One line, quantities 1→3→10, totals EUR 10→30→100; cart badge follows quantity; refresh preserves units. Boundary partitions: empty/single/multiple items; quantity zero/negative/fractional/
normal/UI maximum/stock overflow; valid/unknown/repeated promotion; anonymous/valid/
forged/customer-to-admin identity; incomplete/complete/repeated checkout; own/foreign
customer resources. Monetary assertions use seeded independent arithmetic, not a
second call to the same production calculation.
